# CSS Practice Tasks

This repository contains beginner-level CSS tasks created using Visual Studio Code.
The objective of these tasks is to understand how CSS is used to style and design webpages.

---

## Task 1 – CSS Syntax

Learned the basic syntax of CSS including selectors, properties, and values.
Applied simple styles to HTML elements like headings and paragraphs.

---

## Task 2 – Types of CSS

Implemented the three types of CSS:

* Inline CSS
* Internal CSS
* External CSS

Understood how each type is applied and their differences.

---

## Task 3 – CSS Selectors

Practiced different types of CSS selectors:

* Universal selector
* Element selector
* Class selector
* ID selector
* Group selector
* Descendant selector
* Pseudo-class selector

These selectors help target specific elements for styling.

---

## Task 4 – Fonts, Colors, and Text Styling

Applied various CSS properties such as:

* Font family, size, and style
* Text color and background color
* Text decoration and transformation

This task helped understand how to improve the appearance of text.

---

## Task 5 – Background and Borders

Implemented:

* Background colors and background images
* Different border styles like solid, dashed, dotted, and double

Learned how to enhance visual design using backgrounds and borders.

---

## Task 6 – Margin and Padding

Studied the difference between margin and padding and applied spacing on all sides of elements.
Learned how spacing affects layout and design.

---

## Task 7 – CSS Box Model

Understood the CSS box model which includes:

* Content
* Padding
* Border
* Margin

Applied these properties to create properly spaced layouts.

---

## Task 8 – Tables and Positioning

Styled HTML tables using CSS including:

* Table headers and data cells
* Hover effects

Also implemented CSS positioning:

* Sticky header
* Fixed sidebar
* Fixed footer
* Relative and absolute positioning
* Modal popup using z-index

---

## Task 9 – Navigation, Overflow, and Display

Created:

* Horizontal navigation menu
* Vertical navigation menu
* Dropdown menu
* Responsive menu

Practiced overflow properties:

* Scrollable containers
* Hidden overflow content
* Image overflow handling

Also demonstrated display properties:

* Block
* Inline
* Inline-block

---

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* GitHub

---

## Purpose of the Project

The goal of this project is to build a strong foundation in CSS by practicing different styling techniques, layout methods, and responsive design concepts.
